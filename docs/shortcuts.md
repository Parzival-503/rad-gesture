# Shortcuts on the reading workstation

Generated by `python3 tools/hotkey_audit.py`. Do not edit by hand: change the
scripts (or `tools/external_hotkeys.json` for Rad Optimizer) and re-run it.

**Clashes: none**


## Close these before installing RadGesture

| Old script | Key | Now belongs to |
|---|---|---|
| old RadGesture (Kando) | Ctrl+CapsLock | RadGesture helper (Open the ring (hold)) |
| standalone RadProofread | Ctrl+Alt+Q | RadGesture helper (Proofread) |
| standalone RadOneLiner | Ctrl+Alt+U | RadGesture helper (One-liner) |
| standalone Lung-RADS | Alt+Shift+L | RadGesture helper (Lung-RADS) |

## Shared on purpose

- **Ctrl+Alt+F4**: Rad Optimizer turns dictation on and RadStopwatch (~ passes the key through) starts the study timer: one press, both.
